Laundry Shop Management System

 Project Overview

The Laundry Shop Management System is a web-based system designed to help laundry shop owners and staff manage their daily operations more efficiently. It provides an organized way to handle customer information, laundry services, staff records, laundry orders, and payment transactions.

The system aims to reduce manual record-keeping, improve data organization, and make it easier to monitor laundry shop activities.

 Project Objectives

The main objectives of this project are to:

- Organize and manage customer information.
- Manage laundry services and service types.
- Keep records of staff members.
- Monitor and manage customer laundry orders.
- Record and track payment transactions.
- Improve the accuracy and organization of laundry shop records.
- Make daily laundry shop operations easier and more efficient.

 System Features

The system includes the following modules:


 Dashboard - Displays an overview of the laundry shop's activities. 
 Customers-  Manages customer information and records. 
 Services - Manages available laundry services and their prices. 
 Staff - Stores and manages staff information. 
 Service Type - Organizes services according to their categories. 
 Laundry Orders-  Manages customer laundry orders and order details. 
 Payments - Records and monitors customer payments. 

 Technologies Used

The project uses the following technologies:

- HTML – Creates the structure of the web pages.
- CSS – Designs and styles the user interface.
- JavaScript – Used for interactive features when implemented.
- PHP – Intended for server-side processing and database operations.
- MySQL – Stores and manages system data.

 Database

The system uses a MySQL database named:

laundry_shop_db

The database is designed to store information related to customers, staff, services, laundry orders, order items, payments, machines, and machine usage.

 Current Project Status

The project is being developed in stages:

- Initial Planning: Project objectives, scope, and system requirements.
- Database Design: Database structure and sample records.
- Web Design: HTML and CSS pages for the system interface.
- System Development: Server-side processing and database integration.
- Testing: Checking system functionality and identifying errors.

 Project Purpose

This project is developed as an academic requirement to apply knowledge and skills in database management, web design, and system development. It demonstrates how a computerized system can help improve the organization and management of a laundry shop.
